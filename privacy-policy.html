Curry

Privacy Policy

Last updated: October 28, 2026

Curry is a desktop application for capturing and organizing desktop notifications and showing screen-edge glow effects. Curry is designed to keep its application data on your device. This policy explains what the app accesses, what it stores, and when it connects to an external service.

1. Information Curry processes

When notification monitoring is enabled and permitted by your operating system, Curry reads desktop notifications so it can display them and apply your glow settings. A notification may contain its title, message text, source application name, and timestamp. Notification contents can include personal or sensitive information that another app put in the notification.

Curry can also read application names and executable information from local Start Menu and Desktop shortcuts and Windows uninstall registry entries when you ask it to scan for applications. This information is used to create or update application profiles.

Curry does not require you to create an account. The codebase reviewed for this policy contains no analytics or telemetry service integration.

2. Local storage and retention

Notification history, application profiles, preferences, and glow settings are saved locally in Curry's application configuration directory. Notification history is limited to the history capacity configured in the app. The data remains subject to your device's access controls, backups, and security settings.

You can manage or clear notification history and profiles in the app. Removing Curry or clearing its data through your operating system may not remove separate backups or files you have copied elsewhere.

3. Network access and updates

Curry includes an automatic update checker. Automatic checks are enabled by default and can be turned off in the app's settings; you can also check for updates manually. Curry checks the project's GitHub release endpoint for update information and, if you choose to install an available update, downloads the update from the configured hosting service.

These update connections necessarily disclose network request information to GitHub, such as your IP address and standard connection metadata. The app does not intentionally send notification contents, application profiles, or preferences as part of its update-checking code. GitHub handles request data under its own privacy policy and practices.

Other than update checking and downloading, the reviewed application code does not make external network requests as part of its core notification, profile, or settings features. Operating systems, security software, or distribution platforms may make their own network connections outside Curry's control.

4. Analytics, advertising, and tracking

The reviewed Curry code does not include behavioral analytics, advertising trackers, or a telemetry endpoint. Curry does not intentionally transmit usage analytics to a Curry-operated service.

5. Third-party services and website

GitHub hosts Curry's source code and update releases. When Curry connects to GitHub for update information or downloads, GitHub may process technical request data under its own policies.

This policy describes the Curry desktop application. If this page is hosted by GitHub Pages, GitHub may separately process information about website visitors under GitHub's privacy policy.

6. Data security

Curry stores its application data on your device. Protecting that data also depends on your operating system, device access controls, and backup practices. Keep your operating system up to date and use appropriate protections for your computer.

7. Children's privacy

Curry is a general-purpose desktop utility and is not designed to collect personal information from children. Because notification text may contain information provided by other applications, use appropriate device and account settings for anyone using the computer.

8. Changes to this policy

This policy may be updated when Curry's features or data practices change. The current version will be published on the official project site.

9. Contact

For questions about this policy or Curry's privacy practices, contact the maintainer through the official Curry GitHub repository.

Curry is designed to process notification and application data locally. Update checks connect to GitHub as described above.
