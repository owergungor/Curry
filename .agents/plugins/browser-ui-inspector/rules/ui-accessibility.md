# UI & Accessibility Rules

- All interactive controls (buttons, tabs, inputs, dropdowns) must have accessible labels and keyboard focus outlines.
- Modals and dropdowns must support Escape key dismissal and click-outside closing.
- Color pickers must sanitize HEX and RGB inputs and provide visual previews.
- Glow animations must maintain OLED burn-in protection limits.
