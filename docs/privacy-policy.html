Privacy Policy

Curry: Notification Companion

Effective Date: October 28, 2026 • Microsoft Store ID: 9P2STBW88PDQ • Version 3.3

Summary: Local Notification Processing & Zero Telemetry

Curry is a privacy-first desktop application. All notification processing, alert parsing, and edge glow animations occur strictly on your local computer. Notification data is never collected or uploaded to any remote server. Network connections are limited strictly to anonymous GitHub release update checks in the standalone edition.

1. Information We Do Not Collect

Unlike cloud-connected notification aggregators, Curry operates with a strict zero-telemetry policy:

  • Zero Network Analytics: We do not embed Google Analytics, Mixpanel, Sentry, TelemetryDeck, or any other tracking SDKs.
  • No User Accounts: You do not need to register, provide an email address, or log in to use Curry.
  • No Notification Uploads: The titles, text bodies, sender names, and icons of your incoming desktop alerts are never transmitted over the internet.
  • No Device Fingerprinting: We do not collect hardware identifiers, MAC addresses, IP addresses, or unique machine GUIDs.

2. Windows Notification Listener (WinRT)

To illuminate display borders when notifications arrive, Curry requires access to the Windows UserNotificationListener API:

  • Local Event Processing: Incoming alerts are delivered by the Windows kernel directly to the local Curry process in memory.
  • Purpose Limitation: Notification metadata (such as application name or category) is used solely to match configured glow rules (e.g., triggering a magenta sweep for Slack or green pulse for Teams).
  • Memory-Only History: Notification history is held in an in-memory ring buffer (up to 200 items by default) strictly for your local search and review. It is never uploaded to any remote server or persistent cloud database.
  • Revocation: You can revoke notification access at any time through Windows Settings under Privacy & security > Notifications.

3. Local Storage and Preferences

All configurations and preferences are kept exclusively on your local system:

  • Configuration Directory: User preferences (theme selection, custom glow animations, per-app color rules, monitor routing) are stored in your local application directory (%LOCALAPPDATA%\com.curry.app on Windows).
  • Deletion: You can clear notification history or remove application profiles at any time inside the app. Uninstalling Curry completely removes the application and its associated local settings.

4. Automatic Updates

Depending on your distribution channel:

  • Microsoft Store Edition: Package updates, licensing verification, and downloads are handled entirely by Microsoft Store infrastructure. Curry does not initiate separate update connections.
  • GitHub Standalone Edition: The integrated updater checks for new releases by sending an anonymous HTTPS query to the public GitHub Releases API (https://api.github.com/repos/owergungor/Curry/releases/latest). No identifying user data is included in this request.

5. Children's Privacy

Curry does not collect information from anyone, including children under the age of 13.

6. Third-Party Links

The application and this website may contain links to external sites (such as GitHub or Microsoft Store). We are not responsible for the privacy practices or content of third-party websites.
